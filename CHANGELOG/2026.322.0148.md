# 2026.322.0148 — feat(boxes)!: rename the GPU boxes to a -cdi suffix and compose layer-cdi

## Summary

**Successor to opencharly/distro-fedora#125**, which the validator auto-closed at its fifth BLOCK round
(`AI_REVIEW_AUTO_CLOSE_AFTER`). Same tree (`473008e`); both findings from that round are fixed in it — the
bed description no longer lists a CPU desktop as a GPU-base consumer, and `immich-ml-cdi`'s relationship to
the contract is accounted for below.

The Fedora half of the CDI cutover, mirroring the merged opencharly/distro-cachyos#196. A box that cannot serve
without a GPU now says so in its name, and this repo's GPU base composes the CDI contract.

Five boxes renamed (directory and top-level key), which is every GPU-requiring box this repo declares
that is not already accounted for below:

```
nvidia               -> nvidia-cdi
comfyui              -> comfyui-cdi
immich-ml            -> immich-ml-cdi
jupyter-ml-notebook  -> jupyter-ml-notebook-cdi
python-ml            -> python-ml-cdi
```

**`immich-ml-cdi` is the sixth, and it is deliberately different.** It is a GPU box and carries the suffix,
but it keeps `base: fedora` and takes `layer-cuda` directly (immich needs its own base), so it does not
compose the GPU base and therefore does not inherit `layer-cdi` from it. Its `layer-cuda` advance is a
separate producer hop: `layer-python-ml` still requires `v2026.290.1513`, and composing the contract here
would put two `layer-cuda` refs in one scope (`charly box validate` refuses it — measured). So this PR
renames it and leaves its cuda pin with that hop, rather than claiming a contract it does not carry.

Every reference moves with them — and these are the counts, read from the diff rather than assumed:

```
$ git diff origin/main -U0 | grep -E '^-.*base: nvidia$' | wc -l

$ git diff origin/main -U0 | grep -E '^\-.*image: (nvidia|comfyui|immich-ml|jupyter-ml-notebook|python-ml)$' | wc -l

$ grep -rnE '^\s*(base|image): (nvidia|comfyui|immich-ml|jupyter-ml-notebook|python-ml)$' box/*/charly.yml charly.yml | wc -l

```

Four `base: nvidia` lines (`comfyui-cdi`, `jupyter-ml-notebook-cdi`, `python-ml-cdi`, and
`unsloth-studio`, which bases on it without being a GPU box of its own) and one deploy `image:`
(`check-nvidia-pod`). The last command is the completeness claim, measured: **zero** stale references to
any renamed box remain anywhere in this repo. `jupyter` stays unrenamed — it is CPU-only.

The GPU base's own pins advance in the same change, because the contract cannot be composed on the old
ones:

```
layer-nvidia  7766a9d0…            -> v2026.320.1938
layer-cuda    v2026.314.0705       -> v2026.321.1520   (the driver-user-space strip)
layer-cdi     (not composed)       -> v2026.321.1745   (the CDI contract)
```

and the comment that explained the old `nvidia` pin is rewritten rather than left describing a state that
no longer applies (R5).
