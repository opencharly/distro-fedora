### RCA of the earlier dev/worktree warning

The previous gate paste contained the startup notice `WARNING: charly is a dev/worktree build (not installed at /usr/bin or /usr/local/bin); NOT loading the installed package's plugins from /usr/lib/charly/plugins...`. Root cause (charly `plugin_loader.go`, `warnSkippedFHSPlugins`): the notice fires when the running binary is NOT installed at `/usr/bin` or `/usr/local/bin` (i.e. a dev/worktree build) AND the host's installed-package plugin dir `/usr/lib/charly/plugins` exists with baked plugins. It is a deliberate, documented skip (charly issue #328): a dev binary must not silently load plugins built against a different charly version. It is a startup notice about plugin loading, not a validation finding — the `0 warnings, 0 errors` in the validate result counts validation findings (candy/box/deploy schema issues), which is accurate. The clean re-run above (environment without the FHS plugin dir) produces the identical validation result with no notice, confirming the claim.
