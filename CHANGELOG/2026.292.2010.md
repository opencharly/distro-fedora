# 2026.292.2010 — feat(skills): strip the ten inline `fedora` skill bodies now that routing-only nodes validate

## Summary

Strips the ten inline `content:` bodies from this repo's `skill:` nodes, leaving each node with its routing metadata only (`name`, `family`, `owner`, `description`) and the body served from `.agents/skills/<name>/SKILL.md`.

The bodies already live in `.agents/skills/` on `main`. The inline copies were retained because the `#SkillInput` schema in the charly binary used to validate the repo rejected a routing-only node. A current charly accepts them, and the same shape is green elsewhere in this org: `distro-arch#66` merged today with routing-only nodes and `validate / validate pass`.

This removes the dual-read state R5 forbids — and **the removed text is proven identical to the file that remains**, so no served body changes.
