# 2026.319.1027 — feat(bed): prove the Qdrant RAG vector store in check-openwebui-qdrant-pod

## Summary

Compose Open Web UI with the qdrant layer as a first-class Fedora box and prove the RAG
vector-store contract on a disposable bed.

- `box/openwebui-qdrant` — `pod-openwebui:v2026.319.0943` + `layer-qdrant:v2026.314.0709` on
  the Fedora base. In one deploy the qdrant layer's `env_provide` (`QDRANT_URL`) is rewritten to
  `localhost` by the same-deploy rule and its `secret_require` key (`charly/api-key/qdrant`) is
  consumed by the openwebui candy's `secret_accept` — the same provide/secret contract as the
  two-pod production shape, with no deploy ordering to get wrong.
- `check-openwebui-qdrant-pod` — the disposable witness. It asserts the served open-webui
  version, that Open WebUI's container reaches Qdrant **with the credential the secret_accept
  injected** at the URL the provide supplied, and that a collection written with that credential
  is listed back by the server. It re-asserts nothing the openwebui candy already covers
  (service, HTTP 200, admin env) — a box-level duplicate of those would pass for the wrong
  reason (R2).
- Fixes #111: `check-openwebui-pod` asserted `0.12.3` while the box pins the 0.13.3 candy, so
  the Fedora bed was red for the wrong reason. The assertion now moves with the pin.
