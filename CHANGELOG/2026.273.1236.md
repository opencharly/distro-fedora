# 2026.273.1236 — fix(box): one source per layer for 4 fedora boxes (#717, #739)

## Summary

One-source-per-layer alignment for the **4 non-coder fedora boxes** behind
`opencharly/charly#717` / `#739`: each listed a pod directly **and** a meta-layer that composes
it at a different tag, so the resolver arbitrated between them and emitted a within-box
multi-tag warning. This change makes each candy resolve from **ONE** source — bump the composing
meta-layer to its newest stamp-free tag (which composes the pod at **≥** the box's pin) and/or
drop the redundant direct pod ref. **No downgrade**, verified per box below.
